## About Me

I'm a software engineer working primarily in the **MERN stack**, building applications end to end — from React interfaces to Node/Express APIs and database design. Alongside that, I'm increasingly drawn to **AI-powered tooling**, looking for practical ways to integrate intelligent features into the software I build rather than treating AI as a separate interest.

I care about writing clean, maintainable code, understanding the systems I build rather than just shipping features, and steadily growing as an engineer through real projects.
